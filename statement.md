1. Problem Statement

Manually calculating student marks and ranks takes time and can cause errors. This project creates a simple system to calculate marks, averages, and ranks and display the results clearly.

2. Scope of the Project

The project can calculate total marks, average marks, and rank of multiple students in different subjects. It also checks whether the entered marks are valid.

3. Target Users

- Students
- Teachers
- Schools and colleges

4. High-Level Features

- Enter student name, roll number, and marks.
- Calculate total and average marks.
- Arrange students based on their marks.
- Assign ranks automatically.
- Give the same rank for equal marks.
- Display results in a simple leaderboard.
