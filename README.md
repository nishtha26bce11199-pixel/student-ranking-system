# student-ranking-system
A basic python-based Student Ranking System developed as a beginner level project. The program arranges the students according to their performances by taking students details and marks, and then by calculating their total marks. It also gives same rank to the students having equal marks. 

Student Ranking System

1. About The Project

This is a basic python-based project made to calculate and display the ranks of students based on their marks.
The student mentions the number of students, student names, number of subjects, roll numbers, and marks. The program then calculates the total and average marks and gives each student a rank.

2. What This Project Does

- Takes student details as input
- Take marks of students in each subject
- Calculates total marks and average
- Arranges students according to their total marks.
- Assigns ranks to students.
- Gives the same rank to students with equal marks
- Displays a simple leaderboard

4. Steps to Install and Run

Step 1: Install Python

Download and install Python 3 on your computer.
During installation, select "Add Python to PATH".

Step 2: Open the Project

Open the project in Spyder or any Python editor.

Step 3: Open the Python File

Open the file:
student_ranking_system.py

Step 4: Run the Program

Open the terminal in Spyder and type:
python student_ranking_system.py

Press 'Enter' to run the program.

Step 5: Enter the Input

Enter the required information:

- Number of students
- Number of subjects
- Student name
- Roll number
- Marks for each subject

The program will calculate the results and display the leaderoard.

5. Instructions for Testing

The program can be tested using different types of inputs.

Test 1: Normal Input
Enter valid student details and marks between 0 and 100.

Expected Result:
This program should correctly calculate the total, average and rank.

Test 2: Equal Marks
Give two students the same total marks.

Expected Result:
Both students should receive the same rank.

Test 3: Invalid Marks
Enter a mark greater than 100 or less than 0.

Expected Result:
The program should show an error and ask for the marks agian.

Test 4: Invalid Number Input
Enter names instead of letters for the number of students.

Expected Result:
The program should display an error and stop safely.
